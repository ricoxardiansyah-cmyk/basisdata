## 2. Analisis Wajib

### A. Pembahasan Titik Analisis 1–4
1. **Titik Analisis 1:** Pemisahan akun pengembang (`dev_090`) dan mahasiswa (`mhs_090`) dilakukan untuk menerapkan prinsip *Least Privilege*, memastikan setiap pengguna hanya memiliki hak akses (*privilege*) yang sesuai dengan peran operasionalnya.
2. **Titik Analisis 2:** Perubahan `sql_mode` mempengaruhi fleksibilitas penulisan query dan ketatnya validasi data yang dimasukkan ke dalam basis data.
3. **Titik Analisis 3:** Penggunaan mode autentikasi `cookie` pada phpMyAdmin memerlukan masukan nama pengguna dan kata sandi secara eksplisit saat sesi dimulai, sehingga meningkatkan keamanan dibanding mode `config`.
4. **Titik Analisis 4:** Pengelolaan repositori menggunakan Git memastikan setiap perubahan berkas skrip terisolasi, terrekam riwayatnya, dan terverifikasi secara aman sebelum digabungkan ke cabang utama.

### B. Perbedaan Kode Galat (Error Code)
- **Galat 1044 (Access Denied for User to Database):** Terjadi ketika pengguna berhasil masuk ke dalam sistem basis data, tetapi tidak memiliki izin/hak akses untuk membuat, membaca, atau memodifikasi database tertentu.
- **Galat 1045 (Access Denied for User - Invalid Credentials):** Terjadi saat otentikasi awal gagal, seperti akibat salah memasukkan nama pengguna (*username*) atau kata sandi (*password*).
- **Galat 1142 (Command Denied to User for Table):** Terjadi ketika pengguna berhasil mengakses database, namun tidak memiliki izin untuk menjalankan perintah SQL tertentu (seperti `SELECT`, `INSERT`, `UPDATE`, `DROP`) pada tabel yang dituju.
